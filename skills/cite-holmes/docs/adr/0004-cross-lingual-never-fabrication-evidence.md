# ADR-0004: 跨语言差异永不作为编造依据

日期: 2026-10-11 · 状态: Accepted

## 决策

声称标题与注册库登记标题**语言不同**时，相似度低不构成 invalid 依据：
守卫路径只允许"partial 转人工"或"跨语言桥接核验命中后升级 verified"，
方向只有这两条。

## 背景

中文期刊在注册库登记英文题名是常态，用户引用中文原题天经地义——跨语言
相似度天然接近零，拿它判"编造"会制造系统性冤案。桥接核验（original-title/
落地页/OpenAlex）给出机器可判的升级通道；未命中时保持人工复核，宁缺毋错。

## 后果

- 中文文献第一次获得 verified 通道（此前一律 partial）
- 桥接命中的 note 附带登记原题，保留一秒人工确认的入口
