# ADR-0001: 判定契约——adjust ∈ 三值，一致=空串

日期: 2026-10-11 · 状态: Accepted

## 决策

`doi_metadata_match` 等核验函数的返回契约固定为三值：`""`（一致/无调整）、
`"partial"`（降级）、`"invalid"`（判死）。**"一致"用空字符串表达，不引入
`"verified"` 字面量**——调用方以"无调整"语义处理，避免任何下游把返回值
直接当 verdict 字符串透传。

## 背景

开发中曾出现桥接分支返回字面 `"verified"` 的实现——函数契约被破坏后，
真网实验被外层兜底文案掩蔽、表现偶然正确，只有 mock 测试抓住了它。
这正是不引入第四个字面量的理由：返回值空间越小，「失败被伪装成正常值」的面越小。

## 后果

- 新增核验路径时必须复用三值；想要表达"核验通过"就返回空串+matched=True
- 契约有回归测试锁定（tests/test_v3100.py 契约用例）
