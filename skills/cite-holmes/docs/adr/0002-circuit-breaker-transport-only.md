# ADR-0002: 断路器只记传输层失败

日期: 2026-10-11 · 状态: Accepted

## 决策

主机断路器（同一主机连续 2 次传输失败即本批跳过该主机）**只累计传输层
失败**（超时/连接重置/DNS）；HTTP 层失败（404/403/429/500）一律不计数。

## 背景

HTTP 状态码是"站点有响应"的证据——404 是判定输入（编造引用的证据），
429 是限流信号。若把它们计入熔断，连续两条未收录的 arXiv ID（官方 API
正常回 404）就会把整台官方 API 熔断，殃及同主机上完全无关的其他核验路径
（实例：预印本提示的 404 差点殃及第二源确认——审计抓出后立此存照）。

## 后果

- 官方源 404/429 高频场景下断路器不误开
- 全局网络降级（3+ 主机传输失败）同样只看传输层
