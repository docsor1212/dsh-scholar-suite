# ADR-0005: 线索信号只注记，绝不改判定

日期: 2026-10-11 · 状态: Accepted

## 决策

一切"启发式/统计/外部模型"信号——克隆引用对、清单画像、L4 judge、NLI
第三票、fast-judge 预筛、预印本升级提示——**只追加注记或建议，不改变
五态判定**。判定权只在注册库元数据比对。

## 背景

这些信号各有真实误报面：克隆对可能是预印本与期刊版并存，画像近邻簇可能
是合法连续编号，外置裁判可能错。把线索写成判定，一次误报就是一次冤案；
把判定写成线索，成本只是多看一眼。判死的证据必须机检确凿（注册库查无/
标题不符），其余一切保持"建议"。

## 后果

- 报告明确区分「判定」与「人工复核建议」两个区
- 新信号接入时默认注记级；想改判定必须另立 ADR 论证
