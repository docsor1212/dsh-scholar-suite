# 反模式统一清单（常见误用方式集中收录）

> 收拢 README 与 SKILL.md 分散的反模式说明 + 新增易踩坑场景。
> **30 秒入口**：上手前通读一遍；每条都给了「怎么做才对」的替代方案。
> 按场景找文档回 [INDEX.md](INDEX.md)；跑批前环境不确定先 `--doctor`。

1. **不要用写草稿的同一个模型喂 `semantic` 字段**——语义封顶信任结构化模型判定，
   自己审自己等于没审。
   ✅ 替代：换一个独立模型/会话产出 `semantic` 判定，或至少换新会话零上下文重读来源。
2. **不要把 `verified` 理解为"这篇论文支撑我的论断"**——verified 只说明来源存在、
   层级权威、登记元数据与声称一致；"句子是否真被支撑"归语义层。
   ✅ 替代：对每条关键结论配 `semantic` 三元组判定；verified 只回答"这条引用是不是真的"。
3. **MCP 单次批量不要超过 50 条**——超限被拒。
   ✅ 替代：分批调用（每批 ≤50），或直接用 CLI（`--refs` 无上限，`--workers` 控并发）。
4. **不要手改 `mcp/verify_refs.py`**——它是 scripts/ 的 sha 门禁副本。
   ✅ 替代：改 `scripts/verify_refs.py`，然后跑 `mcp/sync_engine.sh` 同步副本。
5. **不要忽略报告中的 `needs_human_check` 旗标**——partial/unreachable 带复核指令是有意设计。
   ✅ 替代：把"待人工复核"区当作提交前 checklist 逐条处理，处理完重跑确认降级原因消失。
6. **不要在弱网把 `unreachable` 当"假引用"**——unreachable 是"本次抓不到"，不是"查无此物"。
   ✅ 替代：`--cn`（25s 下限+Crossref 回源）或 `--proxy` 重跑；反复不可达再用 Wayback 存档链人工判断。
7. **不要为求星而自动化点击**（平台红线）——报告页脚的 Star/收藏链接面向人类读者。
   ✅ 替代：把报告发给真人读者；产品的增长靠质量与口碑，不走任何自动化互动。
8. **不要在 `--check-document` 里省略 `--refs`**——上下文核验需要清单核验结果做绑定。
   ✅ 替代：同一次调用同时给 `--refs`（清单）与 `--check-document`（正文），先清单后正文。
9. **不要对中英混合引用的锚词率过度报警**——跨语言混合引用的锚词率天然偏低（内容词不相交）。
   ✅ 替代：按"人工复核候选"处理而非自动判死；清单侧的跨语言守卫会把这类降 partial 转人工。

## v3.10+ 新能力反模式（克隆对 / 跨语言桥接 / 清单画像）

10. **不要把"克隆引用对"注记当定罪**——同题不同 DOI 只说明"至少一个标识有误"，
    也可能是同一论文的预印本 DOI 与期刊版 DOI 并存（合法场景）。
    ✅ 替代：按对逐条看元数据核验结果——真 DOI 判 verified、假判 invalid，克隆注记只负责让两条
    进入你的视野。
11. **不要因为桥接命中就跳过人工看一眼**——跨语言桥接核验依赖注册库 original-title /
    落地页 / OpenAlex 的原语言题名，出版商可控字段理论上可被刻意布置。
    ✅ 替代：桥接命中的条目 note 里带有登记英文原题，扫一眼是否与你认知的论文一致（一秒钟的事）。
12. **不要把清单画像旗标当判定依据**——标识符近邻簇可能就是合法的连续编号（同一论文集），
    年份集中可能就是综述专辑；画像抓的是"整批伪装"的统计线索。
    ✅ 替代：按旗标逐条抽查该簇/该来源；逐条判定永远以注册库核验为准。
13. **不要忽略"预印本已正式发表"提示继续引预印本**——审稿人会挑。
    ✅ 替代：按注记里的期刊版 DOI 更新引用条目后重跑，确认新版 verified。
14. **不要拿 `--offline` 的 partial 当"核验过"**——离线只做结构检查，封顶 partial 是诚实设计。
    ✅ 替代：离线整理好清单字段，联网后重跑拿真实判定（磁盘缓存会让重复条目秒回）。

## 触发词误触发怎么办

- 触发词（深度研究/引用核查/查证等）按语义匹配，短句如"查证一下"若被误触发，
  直接说明真实意图即可（"我只要翻译"）；不产生副作用。
- 若希望某类请求**不**触发引用核验，避免在请求中同时包含"研究/查证/引用"词与
  文献清单。

15. **不要在输入未变时重复同一分析或已被拒绝的调用**——相同输入 + 相同路径 =
    相同结果 + 白烧预算（REA 纪律的同源移植：网络层有断路器，分析层也要有）。
    ✅ 替代：重试前先改变一个输入（换检索式/换信源/换判定路径）或先解除阻塞
    （配代理/补标识符），并把上次被拒的原因写进这次的计划里。
