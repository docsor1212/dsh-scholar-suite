# triage 分级标准（doc-holmes）

> 分级是承诺的边界：对用户说什么话，取决于 triage 判成什么级。判据全部可机器复现。

## 判定流程

1. 打开失败 → **C**（原因写明）。
2. `needs_pass`（加密）→ **C**，提示先 `qpdf --decrypt in.pdf out.pdf`。
3. 采样页（前 3 页 + 长文档中位页）统计：
   - 页均有效字符（去空白）`chars_per_page`
   - 相邻短行相似度 >0.8 的重复对数（图层重复）
   - 跳翻规则命中行（水印/版权/页眉/URL/DOI/页码/伪影）
   - 双栏启发式（仅作引擎 hint，不影响分级）
4. 分级：
   - `chars_per_page < 50` → **C**（无有效文本层）
   - `chars_per_page ≥ 500` 且 重复对=0 且 水印行占比 <2% 且 伪影=0 → **A**
   - 其余 → **B**（原因逐条写进 reasons）

## 为什么是这三个阈值

| 阈值 | 值 | 依据 |
|---|---|---|
| 文本层密实 | 500 字符/页 | 正常排版的期刊页 1500-3500 字符；<500 意味着大量内容不在文本层 |
| 无有效文本层 | 50 字符/页 | 纯扫描件残留 OCR 层/水印的典型水平 |
| 水印占比 | 2% | 阅读台脏语料实测：噪声行 ≥2% 时译文必然被污染 |
| 图层重复相似度 | 0.8（仅 <40 字符短行） | 标题多图层重复×3 的实锤形态；长行正文重复（表头）不误伤 |

## 每级对用户的承诺（与 SKILL.md 一致）

- **A**：高保真。公式/图表/目录按原样保留（引擎 IR 层处理，非文本重排）。
- **B**：可翻译，报告明示噪声类型与数量；**span 级图层重复精确检测**（同文+近位置冗余计数入审计；redaction 手术经实测会摧毁重叠字形，刻意不做），粘连拆分模块（wordninja 可选，缺失时保守不拆）已就绪，当前用于审计统计，OCR 通路接线在后续版本。
- **C**：预览质量。OCR 实验通道（tesseract），产物自动加中英双语"预览质量说明页"，audit 里 `tier=C`。

## API

```python
from doc_holmes.triage import triage_pdf, triage_path
rep = triage_pdf("paper.pdf")          # TriageReport（.tier/.reasons/.engine_hints…）
reports = triage_path("~/pdfs")        # 目录递归
```

`--json` 输出 = `TriageReport.to_dict()`，字段稳定，可作上游编排的输入。
